The rule was changed after the final review, because HLS and suffix-less links gave empty pages.
- **From OpenSubtitles: built with a user-pasted key** (`qt-opensubtitles-key`, a password row in Settings ▸ Network). User-confirmed default; the alternative was hiding it and leaving it to VLSub.
  - Uses REST `api.opensubtitles.com/api/v1` and Qt6Network.
  - Hardened: https only, no private hosts, 5 MB cap, no key on redirects.
  - No auto-search on choosing the origin, because that would send the file name to a third party without a click.
- **Customize Player is an in-window overlay; the four form dialogs are modal frameless windows.** Customize must share a drag surface with the live bars; the form frames are bigger than VLC's default window.
  - Form dialogs share `dialogs/dialogs/qml/DialogCard.qml`, extracted from SettingsWindow.
  - Their Loaders live in `MainInterface.qml` (`dialogWindows`), so a view change doesn't destroy them.
- **Customize Player data model:**
  - Two new profile identifiers, `Topbar` and `SeekRow`, and new control ids `0x2B…0x45`, so saved ints stay valid.
  - The seekbar is mandatory and moves only between SeekRow and inline.
  - The player's title bar is model-driven; the library's LocalTopbar stays fixed.
  - Figma outranks the plan: empty zones are dashed only while dragging; the default title bar right group is min, max, fullscreen, close; the palette adds removed default controls after the Figma's.
- **Legacy dialogs:**
  - Toolbar Editor QML is deleted.
  - Legacy Preferences' Toolbar Editor button is hidden, because it opened the card behind a modal dialog.
  - The legacy hotkeys panel stays reachable through Settings ▸ All settings.
- **No build change for contrib Qt.** Contribs set `FEATURE_network=OFF`, so OpenSubtitles' Qt6Network would break them, but this fork builds on system Qt. Recorded in the Ledger.
