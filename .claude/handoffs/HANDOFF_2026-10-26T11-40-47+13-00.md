## Decisions
- **The user skipped the question round.** Calls not shown in any frame are marked *(my call)* in `docs/superpowers/specs/2026-10-25-vlc-redesign-settings-design.md`.
- **One data file plus one delegate.** Rows are data in `dialogs/settings/qml/SettingsData.js` (pages → sections → rows), drawn by one `SettingsRowDelegate`, with custom rows in `dialogs/settings/qml/rows/`.
  - Alternative: hand-laid QML per page. Rejected because search and the Advanced split both need the row data.
  - Schema conventions: a row is Advanced only if it has `adv: true`; data names custom files (`component: "X.qml"`).
- **Config access goes through a C++ singleton** `SettingsBridge` (`VLC.Dialogs`). PlayerEffects' config helpers moved to `util/vlc_config.cpp` and are shared.
  - Rows hide when `exists()` is false: the option isn't built, or it's obsolete (an obsolete option has no `psz_text`).
- **Changes apply immediately** (the Figma has no OK/Cancel). Config is saved when the window closes (focus is taken first, so field edits commit) and again by libvlc at exit.
- **The legacy PrefsDialog stays.** It opens from General ▸ Advanced ▸ "All settings", from the Hotkeys paths (`prefsDialog(int)`) until slice 8, and as a fallback when nothing receives `showSettingsWindow`.
- **Rulings made during the build:**
  - The player's repeat button wrote `config_PutInt("repeat", enum)`. It now writes `repeat`/`loop` as bools, the way `src/libvlc.c:454` reads them.
  - Font size uses `sub-text-scale`. "Size values" is not built, because `freetype-fontsize` and `freetype-rel-fontsize` are obsolete in VLC 4.
  - Accent: the default is `#D37918` in the SystemPalette and GTK providers, and the redesign's QML reads `theme.accent`. On Windows the provider ignores `qt-accent-color`; that is in the Ledger, with no change made.
  - Hardware-accelerated decoding uses `dec-dev`; `avcodec-hw` is obsolete.
  - The rows for `encoder`, `qt-recentplay-filter` and `spdif` are dropped or hidden (all obsolete).
- **The full Ledger of departures** is in `docs/superpowers/plans/2026-10-25-vlc-redesign-settings.md` `## Ledger`. Roadmap row 7 is marked done.

## Bugs / issues surfaced
- **Fixed:**
  - `ToolTipExt` inside a `T.ToolTip` had no palette, so every tooltip drew magenta. The window sets `colorContext.palette: VLCStyle.palette`.
  - Adding an extension that was already installed deleted the user's file. It now short-circuits when the source and destination are the same file, and copies via a temp file and rename.
  - Remove could delete the wrong extension (stale row index). It now removes by captured path and names the extension in the confirmation.
  - `listHas`/`setListHas` asserted on non-string options.
  - `ExtensionListModel::updateList` didn't reset the model.
  - Reset all now matches the legacy reset (shared `qtResetAllPreferences`).
- **Unverified:**
  - Ctrl+P: Qt Shortcuts never fire on Xvfb, and wl-drive's `key:` doesn't reach VLC for Ctrl.
  - Dragging the window by its title area and resizing from an edge: wl-drive has no drag step.
  - The legacy-dialog fallback branch: unreachable here, because `b_isDialogProvider` is never set.
  - Reset all, which wasn't clicked because it would wipe the profile.
- **Open, minor:**
  - The accent applies only on the next launch.
  - Every dropdown re-queries its choices on each `revision` bump, so the font and language lists get rebuilt while a slider is dragged.
  - The restart prompt after Reset has no transient parent, so on Wayland it may not stack over the window.
  - VLSub is listed twice in the dev tree.
  - The Clear history button doesn't ask first.
  - Custom rows have no info glyph.
