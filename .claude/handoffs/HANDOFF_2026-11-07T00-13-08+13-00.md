## Decisions
- **The user skipped the question round.** Every gap is marked *(my call)* in the spec. The plan's `## Ledger` is the full departures record; read it before touching theme code.
- **One C++ token table**, `style/figmatokens.{hpp,cpp}`.
  - It holds both themes. `SystemPalette.tokens` exposes it to QML as `theme.palette.tokens.<fgA2|bgB1|…>`.
  - The alternative was a QML token singleton. It was rejected because the menu style and C++ need the same values.
- **Five Figma light tokens are overridden**, because the Figma's light values are broken copies:
  - FG/1 → `#161616`, FG/2 → `#2E2E2E`, FG/A4 → `#9B9B9B`;
  - BG/A4 → `#D5D5D5`, BG/A5 → `#DEDEDE`.
- **Off-token dark greys** (e.g. `#171717`) keep their exact dark hex in dark. In light they take the nearest token (`lightPartner()`). This keeps Dark pixel-identical.
- **Accent in Light:**
  - Accent as text or icon reads Accent/Dim (`accentText`), because `#E8851A` on its tint is about 1.5:1.
  - Fills (play pill, seek handle, swatches) keep Accent/Main.
- **System:**
  - The decision order is the desktop portal's `org.freedesktop.appearance color-scheme`, then Qt's `styleHints`, then Light. Qt 6.11 kept a stale Light hint under prefer-dark.
  - The portal is read once and cached.
  - System uses VLC's own title-bar buttons, not GTK CSD images, which were invisible on the dark bar.
- **The player** no longer forces dark while a video plays. Hide UI (MinimalView) still does.
- **The onboarding card stays dark.** Its preview follows the chosen tile.
- **Baked SVG greys** are swapped by `Helpers.themedSvg()` (util/qml/Helpers.qml) in Light only. In Dark it returns the plain path.
