## Decisions
- **Video file kept out of git.** `redesign source.mp4` (147 MB) was in the unpushed commit "some updates". It was amended out (now `49ab42f385`) and ignored via `.git/info/exclude`. The file stays on disk.
- **Medialibrary exit SIGSEGV fixed** with `cannot_unload_broken_library()` on the plugin (`0229b4194e`).
  - The alternative was resetting libmedialibrary's static logger, but there's no public API for that.
  - Cause: libmedialibrary's static `shared_ptr<ILogger>` outlived the dlclosed plugin, leaving a dangling vtable.
- **Waveform gated on PLAYING/PAUSED** (`e46a0e3e37`).
  - When playback stops, the video tracks go before the audio ones, so for a moment a video looked audio-only. The waveform then decoded it a second time (the NAS HEVC file), which tripped the transcode `pcr_sync` assert.
- **Slice 5: restyle native QMenus, don't port them to QML.** One `MenuStyle` (QProxyStyle) is installed app-wide.
  - Why: the dynamic var-built Playback/Video/Audio/Subtitle submenus would be a big port, and native popups can extend past the window and over fullscreen video.
- **Icons:** the Figma's two-tone SVGs, used as-is under `:/redesign/menu/` (not the one-colour icon font). Flipped instances get a `<g>` transform (R3).
- **Profile submenu = VLC control-bar profiles.** The Figma's Movies/Shows/Music/Work are read as placeholders. "New" opens Customize Player.
- **Shortcut column shows VLC's real bindings, display-only** (`'\t'` text, never `setShortcut`): Record is Shift + R, Hide UI is Ctrl + H. Real shortcuts were hijacking skins2's `sendKey`.
- **Core change:** `input_item_Update` keeps SLAVE_PRIORITY_USER slaves (R7). Without it the preparser dropped attached subtitles on about 3 of 4 plays.
- **Shuffle** shuffles the playlist's own tracks, then appends and plays them; the existing queue is untouched (R10).
- **Left out because nothing backs them:** folder menu's Edit Subtitle/Audio Tracks and Info; playlist menu's Add Tracks and Properties. "More ▸" stays in "…"; Quit is dropped from it.
- The full ledger of departures is in `docs/superpowers/plans/2026-10-25-vlc-redesign-menus.md` `## Ledger`.
